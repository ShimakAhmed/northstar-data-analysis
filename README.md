# northstar-data-analysis
Database and Analytics Assignment - NorthStar Case Study

This project was developed for the **Databases and Analytics** module.

## 📂 Notebooks

- **01_Python_Data_Cleaning.ipynb**  
  Data cleaning and preprocessing (handling missing values, duplicates, formatting)

- **02_SQL_in_R.ipynb**  
  SQL analysis using R (delivery, hub, driver, complaint analysis)

- **03_R_Analytics.ipynb**  
  Data visualisation using R (charts and graphs for insights)

- **04_Python_Advanced_Analysis.ipynb**  
  Advanced analysis (KPIs, integration, correlation)

- **05_MongoDB_PyMongo_Optimisation.ipynb**  
  MongoDB operations (CRUD, aggregation, indexing)

## 📊 Summary
The project analyses delivery performance, customer complaints, and operational efficiency using Python, R, SQL, and MongoDB.
